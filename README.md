# Media Enhanced API with Authentication

A RESTful Blog API built with **Node.js, Express.js, and MongoDB**, featuring secure user registration and JWT-based authentication. The API integrates **Cloudinary** for avatar uploads and multi-image blog posts, enabling efficient media storage and management. The project was developed and configured using **Visual Studio Code (VS Code)**, tested with **Postman**, and successfully deployed on **Render**.

## Project Links

- **GitHub Repository:** https://github.com/asembof-tech/media-enhanced-api
- **Live Deployment:** https://media-enhanced-api-731d.onrender.com

## Key Features

- **User Registration:** Allows users to create accounts.
- **JWT Authentication:** Secures access using JSON Web Tokens.
- **Avatar Uploads:** Supports user profile image uploads through Cloudinary.
- **Multi-Image Blog Posts:** Supports uploading multiple images for blog content.
- **Cloudinary Integration:** Provides cloud-based media storage and management.
- **MongoDB Database:** Stores application data.
- **RESTful API Architecture:** Organizes backend functionality through API endpoints.
- **API Testing:** Endpoints were tested using Postman.
- **Cloud Deployment:** Successfully deployed and made accessible through Render.

## Technologies Used

- Node.js
- Express.js
- MongoDB
- JSON Web Token (JWT)
- Cloudinary
- Postman
- Visual Studio Code (VS Code)
- Render
